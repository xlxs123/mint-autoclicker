# 轻点 · Windows 自动点击与宏 v2.0.11

从 [GitHub Releases 下载最新版](https://github.com/xlxs123/mint-autoclicker/releases/latest)，选择 EXE 直接运行，或下载便携 ZIP 解压后运行。升级前先通过旧版托盘菜单“退出”；从源码编译的程序位于 `dist/`。

使用 Windows 系统 .NET Framework 4.8，无第三方运行依赖。勾选“关闭或最小化时收进系统托盘”后，点右上角关闭或按 Alt+F4 会保存方案并隐藏到托盘；托盘菜单“退出”才会停止执行并退出。启动和恢复配置不会自动执行。

## v2.0.11 新增

- **计划任务**：「更多设置 → 计划任务…」可以让 Windows 在指定时间（每天或仅一次）自动启动本程序。到点由系统拉起，只会打开窗口，不会自动开始点击；支持创建 / 更新 / 删除，并显示当前是否已创建。
- 用系统 `schtasks` 实现，任务名固定为 `MintClicker-TimeStart`，只对当前用户生效；带空格的程序路径会自动转义引号。
- 权限不足时对话框会提示用「以管理员身份重启」再试。
- **测试**：新增计划任务参数与对话框布局两组用例，测试总数 29 组 / 88 个断言。

## v2.0.10 新增

- **编辑自动保存**：改完点位、宏步骤或任何设置后，停止操作约 15 秒就会自动写回方案库，不用再手动点「保存」或在退出时保存。运行中、取点中、打开对话框时不会写入；状态栏会显示「已自动保存 HH:mm:ss」，日志里也有记录。
- **运行报告**：每次运行结束后记录轮数、执行动作数、用时和结束原因。托盘菜单新增「运行报告…」，可以查看上次运行的详情（方案、模式、开始时间、平均速度）；结束当次状态栏也会显示简要统计，诊断包里也会带上。
- 顺带修正：等待超时的提示按步骤类型显示（等颜色/等图片各说各的），不再统一写成「等待颜色超时」。
- **测试**：新增自动保存与运行报告格式两组用例，测试总数 27 组 / 79 个断言。

## v2.0.9 新增

- **找图点击**：宏里新增「找图」，可以截取屏幕上的一小块图案作为模板，运行时在目标窗口客户区（未绑定窗口则整个屏幕）里搜索，找到后自动点击图案中心。支持匹配容差、等待超时（0 为不限）、左/右/中键与双击。
- 模板以 base64 PNG 存在方案里，导入导出、复制粘贴都会带着走；尺寸限制 8～200 像素，单个模板不超过 60KB。
- 搜索采用“先抽样、再逐像素验证”的粗略到精细算法，全屏搜索也能在一帧内完成；扫描间隔 250 毫秒，避免占满 CPU。
- **测试**：新增模板匹配、找图点击、找图超时三组用例，测试总数 25 组 / 64 个断言。

## v2.0.8 新增

- **窗口相对坐标**：「更多设置 → 坐标相对目标窗口」勾选后，所有点位、宏步骤、录制结果都改为保存“目标窗口客户区内的偏移量”，窗口移动、拉伸或换分辨率后仍然对准。切换模式时会用当前绑定窗口把已有点位在两种坐标间批量换算；没有绑定窗口时会提示先绑定。运行时每次动作都重新读取窗口位置，窗口在运行中被拖动也能跟上。
- **宏步骤复制/粘贴**：宏列表支持多选，右键菜单或 Ctrl+C / Ctrl+V 复制粘贴步骤，粘贴插入到当前选中项之后，受 1000 步上限保护。
- **测试**：新增相对坐标解析用例，测试总数 22 组 / 52 个断言。

## v2.0.7 新增

- **拖动动作**：宏里新增「拖动」，从一个坐标按住拖到另一个坐标再松开，可设按键和按住时长；录制时按住移动超过 6 像素会记成拖动步骤，而不是单击。
- **布局审计测试**：新增界面自检，把主窗口、更多设置、宏步骤编辑器、热键对话框都建出来，逐个检查文字是否被控件高度裁掉、控件是否越界、同级控件是否互相压住。目前 4 个界面全过，共 50 项断言。
- **修复拖放导致的启动崩溃**：点位列原来的拖动排序用了系统 OLE 拖放，在管理员权限或受限会话下会报「DragDrop 注册失败」，而且在窗口构造阶段抛出，直接弹 .NET 崩溃对话框。已改为不依赖 OLE 的鼠标拖动排序；启动阶段的异常也会写日志并给出提示，不再弹系统崩溃框。
- **修复若干文字裁切**：仪表盘轮数/运行时间、热键对话框标签、宏编辑器颜色相关标签都调整了高度或文案，不再压边。

## v2.0.5 新增

- **录制回放**：动作宏页「录制操作…」，正常操作一遍，鼠标点击、滚轮、按键和停顿自动变成宏步骤。只记录真实输入：连点器自己发出的点击、注入事件和对连点器窗口的操作都不会被录进去。「停止」可用停止热键（默认 F8）。同一位置 400 毫秒内的两次点击合并成双击；间隔超过 40 毫秒记为等待步骤；最多 1000 步。
- **等颜色步骤**：宏里新增「等颜色」，等某个坐标的屏幕颜色变成指定颜色（带容差）再继续。「取色（3 秒）」会采集 3 秒后鼠标所在位置的颜色并同时填入坐标；超时可设为不限，超时则停止运行并在状态和日志里提示。
- **随机化**：间隔可上下浮动 ±N 毫秒（作用于所有等待，含“等待”步骤），坐标可随机偏移 ±N 像素（只作用于明确点位的点击，“跟随鼠标”不会挪动光标）。0 表示关闭。
- **定时开始**：在「更多设置」勾选并指定时刻。按开始后先等着，到点自动开始；若当天该时刻已过则排到明天。等待期间再按开始键取消。
- **运行时长上限**：到点自动停止，适合挂机任务。按运行时间计算，不含暂停。
- **全局热键自定义**：「更多设置 → 设置热键…」可改六个热键（开始/停止、取点、停止、暂停、备用取点、紧急停止）。空着或重复会被拒绝；注册失败会在状态行持续提示并写入日志。热键随方案保存，切换方案会跟着换。
- **版本号**：`src/Version.cs` 的 `AppInfo.Version`，程序集版本、窗口标题、托盘文案都读它。

## 快捷键

| 按键（默认） | 操作 |
|---|---|
| F6 | 开始 / 停止；停止后再开始会从头执行 |
| F7 或 Ctrl+Alt+A | 记录当前鼠标位置；多点模式追加点，宏模式追加点击步骤 |
| F9 | 暂停 / 恢复，保留执行进度和剩余等待 |
| F8 或 F12 | 紧急停止 |
| F11 | 全屏 / 退出全屏 |
| 鼠标移至主屏左上角 5×5 像素区域 | 紧急停止 |

六个全局热键都可以在「更多设置 → 设置热键…」里改成别的组合，改完点「应用」生效。快捷键为全局快捷键，软件不在前台也可使用。注册冲突会在状态行持续提示并写入日志；F6 或 F8 被占用时不能开始。F9 冲突时可用窗口或托盘暂停按钮。录制过程中按停止热键结束录制，而不是停止运行。

## 多点点击

1. 位置模式选择“多点循环”，移到目标按 F7 逐个添加；也可点击“添加位置”，3 秒后记录。
2. 仅勾选的点参与执行。列表支持多选删除、拖拽排序、上移和下移；删除和排序后编号同步更新。
3. 选中点修改按键：左蓝、右绿、中红，屏幕和列表均为白色数字圆点。
4. **此点点击方式**：沿用全局、单击或双击。选择“双击”时，该点每次动作发送一组双击，与“每点动作次数”相乘（次数 3 = 连续 3 组双击）。旧方案没有这个字段，按“沿用全局”处理。
5. **备注**：最多 40 字，显示在列表行首，方便在几十个点里认出“登录按钮”“领取奖励”。
6. X / Y 输入需点击“应用坐标”；停止时默认可直接用左键拖动屏幕圆点，无需先进入编辑模式。松开后同步更新列表和方案中的坐标；拖到屏幕外、紧急停止区或连点器窗口上时还原。
7. “每点动作次数”控制该位置重复多少次，“点内间隔”控制这些动作之间的等待。
8. 完整遍历一次勾选列表算一轮。全局重复次数 0 为不限；停止会重置执行位置，下次从头开始。

“跟随鼠标”和“固定单点”仍可使用，固定单点圆点也可直接拖动。运行、暂停、启动倒计时、取点、绑定目标窗口、录制及打开对话框期间，圆点锁定并穿透；停止后按拖动选项自动恢复。拖动选项随方案保存。

点位落在连点器窗口范围内时，屏幕标记会自动隐藏，移开窗口后重新出现——标记是置顶窗口，否则会盖住界面上的文字和控件。

### 延时规则

- 全局间隔范围 10～3,600,000 ms。每点的前后延时和点内间隔范围 0～3,600,000 ms。
- 默认前延时 0，后延时沿用全局间隔，动作次数 1；旧配置保持原节奏。
- 单独设置后延时会替代全局间隔，不叠加。顺序是：前等待 → 本点的重复动作及点内间隔 → 后等待 → 下一点的前等待。
- 最后一轮的最后一个动作完成后立即结束，不再执行尾部后等待。宏中的“等待动作”本身仍会完整执行。
- 每次到达点位都会执行前等待，包括下一轮和局部循环。全局速率只是全局间隔的换算；运行 2 秒后界面会同时显示实测速率。
- Windows 默认把等待量化到约 15.6 ms。需要更准的短间隔请保持“高精度计时”开启（默认开启）。
- 开了随机化后，所有等待都会在 ±N 毫秒内浮动，实测速率会围绕设定值波动，这是预期行为。

## 开始前的检查

点“开始”时先做一次检查，把所有问题一次列出，例如：

- 固定单点还没取点，或点位跑到屏幕外、进入左上角紧急停止区、落在连点器窗口上；
- 多点模式没有勾选任何点；
- 宏模式没有勾选步骤，或局部循环的起终点不对；
- 目标保护已启用但找不到唯一的绑定窗口；
- 正在录制。

有上述问题时不会开始，按提示修正后重试即可。只有提醒（例如间隔 10 ms 但精度有限）时会问“仍然开始 / 取消”。

## 暂停、高亮与状态

按 F9 暂停，再按 F9 从中断处继续。不会重新点击已经完成的动作；某点执行了 3 次中的 1 次后暂停，恢复后继续剩余次数。暂停期间等待倒计时冻结，运行时间不包含暂停时间。紧急停止在暂停期间仍有效。

当前点在列表中以浅黄色底显示，屏幕圆点增加金色外圈，鼠标穿透不变。状态显示原列表编号、已勾选项中的进度、已完成轮数、点内动作进度和当前阶段的剩余等待毫秒数。界面按约 80 ms 刷新，快速动作可能略过中间高亮。

目标窗口保护触发自动暂停时，如果窗口不在前台，会弹一个托盘气泡提醒；同样的信息也写进日志。

## 动作宏

切到“动作宏”页，添加步骤或用“从点击点追加转换”把现有点位复制为独立宏。原点击点保留，转换后两者分别编辑。F7 / Ctrl+Alt+A 在宏模式下可直接取坐标并追加点击步骤。

支持八类动作：

| 类型 | 参数与行为 |
|---|---|
| 点击 | 坐标、左/右/中键、单击或双击、重复次数、重复间隔 |
| 等待 | 等待指定毫秒数 |
| 按键 | 点击输入框，实际按下所需按键或 Ctrl / Alt / Shift 组合键 |
| 移动鼠标 | 移动到指定 X / Y |
| 滚轮 | 在指定 X / Y 发送滚轮；正数向上、负数向下，1 格为 120 单位 |
| 等颜色 | 轮询指定坐标的屏幕颜色，进入容差范围后继续；超时（0 为不限）则停止运行 |
| 拖动 | 在起点按住，用指定时长拖到终点再松开；可选中/右键 |
| 找图 | 截取一小块图案作为模板，在目标窗口客户区（未绑定则全屏）搜索，出现后点击图案中心；可设容差、超时、按键与双击 |

每步还有独立的执行前后等待。双击列表项或点“编辑”修改参数；仅勾选项执行。鼠标点击步骤显示彩色屏幕编号，其他步骤在列表中使用灰色编号。宏点击标记在停止时可直接拖动并同步步骤坐标。

宏列表支持多选：右键菜单或 Ctrl+C / Ctrl+V 可以复制、粘贴步骤，粘贴插到当前选中项之后。拖动步骤在列表里显示为“拖动 左键 (起点) → (终点) · 按住 N ms”。

全局的重复次数控制整条宏执行几轮；宏步骤中的等待、按键和单双击参数独立于左侧普通点击设置。键盘输入发送给当前前台窗口；滚轮最终作用由目标应用和 Windows 滚动设置决定。宏保留连点器的控制键，不能把 F6/F7/F8/F9/F12 或 Ctrl+Alt+A 设置为宏按键。

### 录制操作

宏页点「录制操作…」开始，正常操作目标窗口，按停止热键（默认 F8）结束，录到的步骤会追加到当前宏列表末尾并自动切到宏页。

- 只记录真实输入：连点器自己发出的点击、其它程序注入的事件、点在连点器窗口上的操作都不会被记录。
- 按住并移动超过 6 像素记成一次「拖动」（记录起点、终点和按住时长），只点一下不移动仍记成单击。
- 同一位置附近（±2 像素）400 毫秒内的两次点击合并为一次双击。
- 两次动作间超过 40 毫秒会插入一个等待步骤，时间按实际间隔；更短的间隔不额外插入，避免步骤爆炸。
- 录制中不能开始运行、取点或改热键；停止热键只结束录制。
- 单次最多 1000 步，超过后不再记录。

### 等颜色步骤

步骤类型选「等颜色」，X / Y 是要观察的坐标。点「取色（3 秒）」后有 3 秒时间把鼠标移到目标位置，到点会读取光标下的颜色并同时填好 X / Y。也可以直接输入 `#RRGGBB`。「颜色容差」允许每个通道 ±N 的偏差；「等颜色超时」为 0 时不限时。

运行时按 50 毫秒轮询。目标窗口被别的窗口挡住时会读到遮挡物的颜色，所以请让目标区域保持可见。超时会以“等待颜色超时”停止整次运行，而不是跳过这一步。

### 一段局部循环

宏页底部可指定起点编号、终点编号和次数。起点 0 或次数 1 表示不重复。起点、终点必须勾选，区间内未勾选的步骤跳过。

例如步骤 A、B、C、D，起点 2、终点 3、次数 2，执行顺序为 A → B → C → B → C → D，再计为完整一轮。支持一段连续局部循环，不支持嵌套；删除或排序后按当前编号解释循环范围。

## 更多设置

- **启动倒计时**：0 / 1 / 3 / 5 / 10 秒，默认 3 秒；0 秒将在点击“开始”后立即准备执行。
- **目标窗口保护**：可以“从窗口列表选择…”，也可以“3 秒后绑定”，在倒计时中切到目标窗口。绑定成功后启用保护。运行时目标失去前台、关闭或进程改变会暂停；切回该目标并按 F9 才会恢复。
- 目标保护检查窗口身份与前台状态，不跟踪窗口内按钮的移动，也不验证页面内容。默认坐标是屏幕绝对坐标，换电脑或分辨率后需要检查点位。
- **坐标相对目标窗口**：勾选后点位改为保存目标窗口客户区内的偏移量，窗口移动或换分辨率后仍能对准。切换模式时会用当前绑定窗口批量换算已有点位；没有绑定目标窗口时会提示先绑定。运行时每次动作都会重新读取窗口位置。
- **高精度计时**：默认开启，运行期间把系统计时精度提到 1 ms，停止后释放。长时间运行时关掉更省电。
- **定时开始**：勾选并选好时刻，按开始后等到该时刻自动开始；当天已过则排到明天。按开始键可取消。
- **运行时长上限**：分钟数，0 为不限；到点自动停止。
- **随机化**：间隔 ± 毫秒、坐标 ± 像素，0 为关闭。
- **设置热键**：六个全局热键，改完应用生效；随方案保存。
- **托盘**：勾选“关闭或最小化时收进系统托盘”后，右上角关闭、Alt+F4 和最小化均收进托盘。右键菜单可开始、暂停/恢复、停止、显示窗口和退出。
- **启动时最小化**：随方案保存，只影响下次打开软件，不会自动执行。
- **登录 Windows 时启动**：默认不启用，只有在软件中主动勾选并应用时才写入当前用户的 Run 项。它属于此电脑的设置，不随方案导入导出。
- **便携模式**：开启后在程序目录生成 `portable.txt`，方案与日志改放 `data\`，重启生效。
- **以管理员身份重启**：保存当前方案后重新以管理员启动；目标窗口是提权程序时需要。
- **计划任务**：让 Windows 在指定时间（每天或仅一次）自动启动本程序。只启动程序、不自动开始点击，任务由系统 `schtasks` 管理，可随时在对话框里删除。

启用目标保护后，在主窗口点击恢复会因主窗口仍在前台而继续暂停，请切回目标使用 F9。纯键盘宏也应先准备好接收输入的窗口。

## 诊断与日志

- 位置：`%LOCALAPPDATA%\MintClicker\logs\app.log`；便携模式下是 `<程序目录>\data\logs\app.log`。
- 内容：启动版本与系统信息、开始/停止及模式与步数、目标窗口绑定、快捷键注册失败、录制开始/结束、方案保存/读取失败、自动暂停、托盘提示、未处理异常堆栈。
- 1 MB 自动轮转，保留 `app.log.1`～`app.log.3`。UTF-8 带 BOM。
- 「更多设置 → 打开日志文件夹」可直接定位。
- 「更多设置 → 导出诊断包…」把版本、系统信息、屏幕、热键、当前方案、方案库副本和日志打成一个 ZIP，发给作者即可排查（注意方案里有自己的点位坐标）。

## 多方案、导入导出与兼容

顶部支持保存、新建、复制、重命名、删除、导入、导出。切换前保存当前方案，正常退出时保存；平时改完点位或设置、停手约 15 秒也会自动保存（运行中、取点中不写）。下次恢复最后使用的方案。至少保留一套，最多 100 套，每套最多 1000 个点击点及 1000 个宏步骤。

导入会新建方案，同名加后缀，不覆盖当前方案，也不自动执行。导出包含当前已应用的编辑内容。坐标输入仍需先点“应用坐标”；更换电脑或显示器后应检查坐标。

默认使用独立文件：

`%LOCALAPPDATA%\MintClicker\settings.profiles.v2.json`

便携模式（程序目录有 `portable.txt`）改为：

`<程序目录>\data\settings.profiles.v2.json`

首次使用时按顺序读取：v2 方案库 → v1.4 的 `settings.profiles.json` → 旧版 `settings.xml`。已有旧文件不改写。保存时使用临时文件替换，并保留上一份 `.bak`；主文件读不出来时自动用 `.bak` 并另存损坏文件为 `.corrupt-时间`。

导出格式 `schemaVersion: 2`。普通点击点在 `settings.Positions`，宏在 `settings.Actions`。按键 0/1/2 分别为左/右/中；动作 Kind 的 0/1/2/3/4/5/6/7 分别为点击/等待/按键/移动/滚轮/等颜色/拖动/找图。普通点 `DoubleClick` 为 -1/0/1 时分别表示沿用全局/单击/双击，`Label` 是备注。全局设置新增 `JitterInterval`、`JitterPosition`、`RunMinutes`、`ScheduleEnabled`、`ScheduleHour`、`ScheduleMinute`、`RelativeCoordinates`，热键为 `HotkeyStart` 等六个“修饰键 << 16 | 虚拟键码”。拖动步骤使用 `EndX`、`EndY` 和 `Duration`；找图步骤使用 `Template`（base64 PNG）、`TemplateWidth`、`TemplateHeight`，容差与超时复用 `PixelTolerance` 和 `Duration`。

兼容性：新增字段对旧版是“缺省即默认”，但**含「等颜色」（Kind 5）、「拖动」（Kind 6）或「找图」（Kind 7）步骤的方案在旧版本会校验失败**，其余宏步骤类型仍可互通。

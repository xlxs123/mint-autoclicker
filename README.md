# 轻点 · Windows 自动点击与宏 v2.0.2

从 [GitHub Releases 下载最新版](https://github.com/xlxs123/mint-autoclicker/releases/latest)，选择 EXE 直接运行，或下载便携 ZIP 解压后运行。升级前先通过旧版托盘菜单“退出”；从源码编译的程序位于 `dist/`。

使用 Windows 系统 .NET Framework 4.8，无第三方运行依赖。勾选“关闭或最小化时收进系统托盘”后，点右上角关闭或按 Alt+F4 会保存方案并隐藏到托盘；托盘菜单“退出”才会停止执行并退出。启动和恢复配置不会自动执行。

v2.0.2 把整个界面按 1.25 倍重新排布，修正 125% 缩放显示器上文字拥挤与标签截断的问题：窗口客户区为 1325×880，两个选项卡改为左右两栏，三个对话框同步放大。注意 `点击点` 面板现在只显示约 3 行点位，其余需要滚动查看。

v2.0.1 修正关闭按钮的托盘行为，并新增停止状态下直接拖动屏幕标记，默认开启。右上角“停止时允许拖动”可切换；点击点面板的“锁定标记（穿透）”也可在停止时改为穿透。

本版合并原路线中的 v1.5～v2.0：暂停恢复、运行高亮和状态、扩展快捷键、可选倒计时、每点重复、Action 宏，并增加目标窗口保护、托盘和可选登录启动。

## 快捷键

| 按键 | 操作 |
|---|---|
| F6 | 开始 / 停止；停止后再开始会从头执行 |
| F7 或 Ctrl+Alt+A | 记录当前鼠标位置；多点模式追加点，宏模式追加点击步骤 |
| F9 | 暂停 / 恢复，保留执行进度和剩余等待 |
| F8 或 F12 | 紧急停止 |
| 鼠标移至主屏左上角 5×5 像素区域 | 紧急停止 |

快捷键为全局快捷键，软件不在前台也可使用。注册冲突会在界面提示；F6 或 F8 被占用时不能开始。F9 冲突时可用窗口或托盘暂停按钮。

## 多点点击

1. 位置模式选择“多点循环”，移到目标按 F7 逐个添加；也可点击“添加位置”，3 秒后记录。
2. 仅勾选的点参与执行，可删除、清空、上移和下移。删除和排序后编号同步更新。
3. 选中点修改按键：左蓝、右绿、中红，屏幕和列表均为白色数字圆点。
4. X / Y 输入需点击“应用坐标”；停止时默认可直接用左键拖动屏幕圆点，无需先进入编辑模式。松开后同步更新列表和方案中的坐标；拖到屏幕外、紧急停止区或连点器窗口上时还原。取消“停止时允许拖动”或点“锁定标记（穿透）”可恢复空闲时的鼠标穿透。
5. “每点动作次数”控制该位置重复多少次，“点内间隔”控制这些动作之间的等待。如果全局选择双击，每次动作发送一组双击；例如次数 3 表示连续 3 组双击。
6. 完整遍历一次勾选列表算一轮。全局重复次数 0 为不限；停止会重置执行位置，下次从头开始。

“跟随鼠标”和“固定单点”仍可使用，固定单点圆点也可直接拖动。运行、暂停、启动倒计时、取点、绑定目标窗口及打开对话框期间，圆点锁定并穿透；停止后按拖动选项自动恢复。允许拖动时圆点会接收鼠标操作，若要手动点击它下方的目标，请先锁定或隐藏标记。拖动选项随方案保存。

### 延时规则

- 全局间隔范围 10～3,600,000 ms。每点的前后延时和点内间隔范围 0～3,600,000 ms。
- 默认前延时 0，后延时沿用全局间隔，动作次数 1；旧配置保持原节奏。
- 单独设置后延时会替代全局间隔，不叠加。顺序是：前等待 → 本点的重复动作及点内间隔 → 后等待 → 下一点的前等待。
- 最后一轮的最后一个动作完成后立即结束，不再执行尾部后等待。宏中的“等待动作”本身仍会完整执行。
- 每次到达点位都会执行前等待，包括下一轮和局部循环。全局速率只是全局间隔的换算，不代表复杂方案的实测速率。

## 暂停、高亮与状态

按 F9 暂停，再按 F9 从中断处继续。不会重新点击已经完成的动作；某点执行了 3 次中的 1 次后暂停，恢复后继续剩余次数。暂停期间等待倒计时冻结，运行时间不包含暂停时间。紧急停止在暂停期间仍有效。

当前点在列表中以浅黄色底显示，屏幕圆点增加金色外圈，鼠标穿透不变。状态显示原列表编号、已勾选项中的进度、已完成轮数、点内动作进度和当前阶段的剩余等待毫秒数。“剩余等待”是当前阶段的等待，不是整轮预计耗时。界面按约 80 ms 刷新，快速动作可能略过中间高亮。

## 动作宏

切到“动作宏”页，添加步骤或用“从点击点追加转换”把现有点位复制为独立宏。原点击点保留，转换后两者分别编辑。F7 / Ctrl+Alt+A 在宏模式下可直接取坐标并追加点击步骤。

支持五类动作：

| 类型 | 参数与行为 |
|---|---|
| 点击 | 坐标、左/右/中键、单击或双击、重复次数、重复间隔 |
| 等待 | 等待指定毫秒数 |
| 按键 | 点击输入框，实际按下所需按键或 Ctrl / Alt / Shift 组合键 |
| 移动鼠标 | 移动到指定 X / Y |
| 滚轮 | 在指定 X / Y 发送滚轮；正数向上、负数向下，1 格为 120 单位 |

每步还有独立的执行前后等待。双击列表项或点“编辑”修改参数；仅勾选项执行。鼠标点击步骤显示彩色屏幕编号，其他步骤在列表中使用灰色编号。宏点击标记在停止时可直接拖动并同步步骤坐标；也可在步骤编辑器修改坐标。

全局的重复次数控制整条宏执行几轮；宏步骤中的等待、按键和单双击参数独立于左侧普通点击设置。键盘输入发送给当前前台窗口；滚轮最终作用由目标应用和 Windows 滚动设置决定。宏保留连点器的控制键，不能把 F6/F7/F8/F9/F12 或 Ctrl+Alt+A 设置为宏按键。

### 一段局部循环

宏页底部可指定起点编号、终点编号和次数。起点 0 或次数 1 表示不重复。起点、终点必须勾选，区间内未勾选的步骤跳过。

例如步骤 A、B、C、D，起点 2、终点 3、次数 2，执行顺序为 A → B → C → B → C → D，再计为完整一轮。支持一段连续局部循环，不支持嵌套；删除或排序后按当前编号解释循环范围。

## 更多设置

- **启动倒计时**：0 / 1 / 3 / 5 / 10 秒，默认 3 秒；0 秒将在点击“开始”后立即准备执行。
- **目标窗口保护**：点击“3 秒后绑定目标窗口”，在倒计时中切到目标窗口。绑定成功后启用保护。运行时目标失去前台、关闭或进程改变会暂停；切回该目标并按 F9 才会恢复。
- 目标保护检查窗口身份与前台状态，不跟踪窗口内按钮的移动，也不验证页面内容。坐标仍是屏幕绝对坐标。程序重开后用窗口标题和进程名找唯一目标，找不到或存在重名窗口时需重新绑定。
- **托盘**：勾选“关闭或最小化时收进系统托盘”后，右上角关闭、Alt+F4 和最小化均收进托盘，保留当前任务状态；双击图标恢复。右键菜单可开始、暂停/恢复、停止、显示窗口和退出。选“退出”真正停止并关闭程序；取消托盘选项后，关闭按钮也会真正退出。Windows 注销/关机不拦截为托盘隐藏。启用目标窗口保护时，切换前台仍可能触发自动暂停。
- **启动时最小化**：随方案保存，只影响下次打开软件，不会自动执行。
- **登录 Windows 时启动**：默认不启用，只有在软件中主动勾选并应用时才写入当前用户的 Run 项。它属于此电脑的设置，不随方案导入导出。移动 EXE 后需取消再重新启用，以更新路径。

启用目标保护后，在主窗口点击恢复会因主窗口仍在前台而继续暂停，请切回目标使用 F9。纯键盘宏也应先准备好接收输入的窗口。

## 多方案、导入导出与兼容

顶部支持保存、新建、复制、重命名、删除、导入、导出。切换前保存当前方案，正常退出时保存；下次恢复最后使用的方案。至少保留一套，最多 100 套，每套最多 1000 个点击点及 1000 个宏步骤。

导入会新建方案，同名加后缀，不覆盖当前方案，也不自动执行。导出包含当前已应用的编辑内容。坐标输入仍需先点“应用坐标”；更换电脑或显示器后应检查坐标。

本版使用独立文件：

`%LOCALAPPDATA%\MintClicker\settings.profiles.v2.json`

首次使用时按顺序读取：v2 方案库 → v1.4 的 `settings.profiles.json` → 旧版 `settings.xml`。已有旧文件不改写。产生 v2 文件后不再自动同步旧版编辑。保存时使用临时文件替换，并保留上一份 `.bak`；失败会明确提示，方案切换不生效，退出时可返回并导出当前内容。

导出格式 `schemaVersion: 2`；兼容导入 v1.4 的版本 1。普通点击点在 `settings.Positions`，宏在 `settings.Actions`。按键 0/1/2 分别为左/右/中；动作 Kind 的 0/1/2/3/4 分别为点击/等待/按键/移动/滚轮。普通点 `DelayAfter: -1` 表示沿用全局间隔。建议以软件导出的 JSON 为模板。

回退时使用自己保留的旧 EXE 和原方案库，v2 新增内容不会自动降级到旧版。开发机上的历史备份和个人方案不随仓库发布。

## 构建与验证状态

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputName AutoClicker-v2.0.2.exe
```

脚本使用系统 C# 编译器，默认只编译主程序，不访问网络、不运行测试。程序集使用系统 Windows Forms、Drawing、XML 和 Web Extensions，无新增第三方依赖。

v2.0.2 已用 `/warn:4 /warnaserror+` 编译通过，无警告。界面尺寸修正的验证方式与数据见 `VERIFICATION.md`：文字越界 0 处、控件截断 0 处、真实控件相互遮挡 0 处，窗口 1331×909 完整落在工作区内且无滚动条；该修正尚未在真实桌面复测点击与拖动。使用者此前已完成全部功能实测并确认“完全可行”，包括关闭到托盘及直接拖动标记，该结论针对 v2.0.1。发布阶段未重复运行应用测试，验收依据为使用者实测反馈。可参考 `手动验收.md` 复查。

`tests/` 仅保留历史测试源码，旧引擎桩和 XML 保存断言尚未适配 v2.0，不能作为当前版本自动测试通过的证明。编译产物通过 Releases 提供，个人方案、临时文件、旧版本备份及本地测试日志不提交到仓库。

使用标准 Windows 输入接口；向管理员权限窗口发送输入可能需要用户手动以管理员身份运行。实际发送成功不等于目标应用已接受操作，受保护程序可能拦截模拟输入。
